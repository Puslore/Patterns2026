| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Единица измерения (Unit) | Простая сущность. Единица измерения массы, объёма или количества: граммы, литры, штуки. | Ингредиент (ассоциация), Группа (агрегация) |
| Деньги (Money) | Простая сущность. Денежная сумма и валюта, используемые для цен и расчётов. | Блюдо / Номенклатура блюд (ассоциация), Контракт (ассоциация) |
| Ингредиент (Ingredient) | Простая сущность. Продукт, для которого указаны количество и единица измерения. | Единица измерения (ассоциация), Блюдо / Номенклатура блюд (агрегация), Технологическая карта (ассоциация), Склад (ассоциация) |
| Адрес / Адрес доставки (Address) | Простая сущность. Адрес ресторана или клиента, куда нужно доставить заказ. | Ресторан (композиция), Заказ (ассоциация) |
| Сотрудник (Employee) | Простая сущность. Сотрудник, работающий в компании. | График работы (агрегация), Контракт (агрегация), Ресторан (агрегация) |
| Контрагент (Contractor) | Простая сущность. Поставщик продуктов или партнёр, с которым сотрудничает компания. | Группа (агрегация), Контракт (агрегация) |
| Группа (Group) | Простая сущность. Категория, объединяющая похожие объекты. | Единица измерения (агрегация), Контрагент (агрегация), Группа (ассоциация) |
| Блюдо / Номенклатура блюд (Dish) | Комплексная сущность. Позиция меню, у которой есть цена и перечень продуктов для приготовления. | Ингредиент (агрегация), Деньги (ассоциация), Технологическая карта (композиция), Ресторан (агрегация) |
| Технологическая карта (Recipe) | Комплексная сущность. Рецепт, в котором указаны точные массы ингредиентов и этапы приготовления. | Ингредиент (ассоциация), Блюдо / Номенклатура блюд (композиция), Технологическая карта (ассоциация) |
| Склад (Storage) | Комплексная сущность. Место, где хранятся продукты и заготовки. | Ингредиент (ассоциация), Ресторан (композиция), Заказ (ассоциация) |
| Ресторан (Restaurant) | Комплексная сущность. Точка сети, у которой есть собственный склад, меню и сотрудники. | Адрес (композиция), Склад (композиция), Блюдо / Номенклатура блюд (агрегация), Сотрудник (агрегация), Заказ (ассоциация) |
| Контракт (Contract) | Комплексная сущность. Договор с поставщиком на покупку продуктов. | Контрагент (агрегация), Сотрудник (агрегация), Деньги (ассоциация) |
| График работы (WorkSchedule) | Комплексная сущность. График рабочих смен сотрудников. | Сотрудник (агрегация) |
| Заказ (Order) | Комплексная сущность. Заказ клиента, содержащий список блюд и адрес доставки. | Ресторан (ассоциация), Склад (ассоциация), Блюдо / Номенклатура блюд (агрегация), Адрес / Адрес доставки (ассоциация) |
