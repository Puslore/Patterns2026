# Письмо

Привет, бро!<br>
Наш проект развивается. Мы представили Заказчику новую версию API в котором теперь возвращает:
- Отчет по любой сущнорсти в указанном формате
- Список типов сущностей
- Оборотно-сальдовую ведомость (ОСВ) с произвольным периодом
- CRUD операции по любой сущности.

Наш Заказчик, резонно, заметил, что если мы удаляем \ меняем доменную сущность, то необходимо 
включить в проект `логгирование`.

Поэтому, предлагаю тебе выполнить данную реализацию.
Необходимо:
1. При работе с CRUD операциями выполнять логирование. Примерно в следующем формате

| Период   | Название подсистемы | Тип сообщения | Сообщение |
|----------|----------------------|---------------|-----------|

Типы сообщений:
- `ERROR`
- `INFO`
- `DEBUG`


2. Добавить в Api метод, который будет лог получать в `Json формате` с фильтрацией и сортировкой.

Дополнительно:
- Если **получится**, то лог получать в указанном формате (в отдельном методе): 

| Формат   | Описание   |
|----------|-------------|
| TXT      |  Скачивать готовый файл. Открывать сразу же в блокноте |
| CSV      | Скачивать готовый файл. Открывать сразу же в эксель | 
| MARKDOWN | Просматривать как тест в браузере |

3. Обязательно, данные методы опубликовать в swagger

Удачи! 
`Вся надежда только на тебя!`
